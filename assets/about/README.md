# Фото для страницы «О нас»

Положите сюда свои фотографии (JPG/WebP, по ширине от 1600 px). Если файла нет, блок с фото на странице
`about.html` просто не показывается — вёрстка не ломается.

| Файл | Где показывается | Что снять |
|---|---|---|
| `interior-1.jpg` | широкий кадр под заголовком | общий вид галереи, вход |
| `interior-2.jpg` | блок «Галерея» | залы, витрины |
| `service.jpg` | блок «Сервис» | примерочная, консультация, персональный шопинг |

Используйте только свои снимки или те, на которые есть права.
