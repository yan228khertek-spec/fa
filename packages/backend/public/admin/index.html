Как это работает

1С отправляет каталог через «Обмен с сайтом» → данные попадают в базу. Брендов в 1С нет — они «зашиты» в названия позиций.

Поэтому бренды ведём здесь, на сайте: у каждого есть название и написания (как бренд встречается в названиях). Модель получает бренд, если одно из написаний есть в её названии. Остальные модели видны во вкладке «Без бренда» — их можно назначить вручную.

Здесь же: разделы (мужское/женское), «Топ бренды», фото и логотипы. Обмен с 1С эти настройки не трогает.

«Пересчитать» — после нового обмена с 1С. «Загрузить список» безопасно: уже существующие бренды не меняются.
